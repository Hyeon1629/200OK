# 체크당 — 와이어프레임 v2 (현재 구현 상태)

> 작성일: 2026-05-22
> 목적: Claude 디자인 의뢰 시 첨부 자료. 현재 구현된 모든 활성 화면의 영역 구조와 콘텐츠 인벤토리.
> **이 문서는 와이어프레임 수준이며, 실제 디자인이 적용되지 않은 상태입니다.**

---

## 0. 앱 컨텍스트

**체크당 (Check-Dang)** — 혈당 + 라이프스타일 통합 관리 + AI 2D 바디맵 분석 Android 헬스케어 앱.

- 플랫폼: Android Native (Kotlin, XML Layout, minSdk 26)
- 디자인 전제: **라이트 모드 전용** (다크 모드 미지원), 한국 사용자 우선
- 주요 사용자: **당뇨 환자 본인 + 가족 대리 기록자** (고령 환자를 가족이 대신 기록하는 케이스 다수)
- 시각 톤: 의료 신뢰감 + 친근함. 의료기기로 보이지 않게 (서비스는 의료기기 아님)

## 4. 디자인 시 핵심 고려사항

### 4.1 사용자 컨텍스트
- **고령 환자 대리 기록 케이스 다수** — 큰 글자/명확한 대비 선호, 시니어 친화적 가독성
- **본인이 아닌 가족이 보고 입력** — 닉네임을 "당신" 으로 직접 호명하지 않음. 카피는 3인칭 ("{닉네임}님의 ...") 으로 작성됨

### 4.2 시각 톤
- **신뢰감** (헬스케어 + 결제) + **친근함** (매일 사용)
- 의료기기로 보이지 않게 — 차갑거나 임상적인 느낌 회피
- 한국 디자인 감성 (토스, 카카오 헬스 등 참고하되 차별화)

### 4.3 컬러 사용
- **brand_green (#4CAF50)** 은 본 앱의 시그니처. 이 색은 유지하되 보조 컬러(액센트, 그라데이션 끝점) 제안 가능
- 상태 컬러 (normal/warning/danger) 는 한국 환자에게 직관적이어야 함 — 현재 신호등 패턴 유지 권장
- 영양소(carbs/protein/fat), 수면(deep/light/REM) 컬러는 시각 일관성 차원에서 재검토 가능

### 4.4 컴포넌트 강화 권장 영역
- **카드 elevation/shadow** — 현재 2dp 단조. 깊이감 살리고 카드 hover/press 상태 추가
- **그라데이션** — 메인 혈당 카드, FAB, 구독 CTA 등 핵심 액션에 그라데이션 강조 고려
- **일러스트** — 빈 상태, 온보딩, 구독 화면. 현재는 텍스트만
- **차트 시각화** — MPAndroidChart 한계 내에서 색상/마커/툴팁 디자인 강화
- **마이크로 인터랙션** — 카드 터치, 토글 전환, 입력 완료 시 피드백

### 4.5 라이트 모드 전용
- 다크 모드 디자인 요청 안 함. `night/` 리소스 폴더 미생성 정책

### 4.6 본 단계 제외
- **바디맵 인체 모형 SVG** — Front/Back 인체 그림 자체는 별도 디자인 단계 (현재는 와이어프레임 박스로 둠)
- **앱 아이콘** — 별도 STEP 에서 확정 완료
- **차트 라이브러리 변경** — MPAndroidChart 그대로 유지 (외부 의존성 추가 정책)
